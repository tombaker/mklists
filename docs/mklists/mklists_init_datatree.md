Usage: mklists init datatree [OPTIONS] [PATH]

  Initialize a new datatree (with shared mklists.rules).

  Creates `mklists.yaml` and `mklists.rules` with commented example content.
  No datadir subdirectories are created. After writing the two files, advises
  the user to create datadirs with `mklists init datadir`.

Options:
  --help  Show this message and exit.
